# BUG-001: El login no muestra mensaje de error con contraseña incorrecta

- **Caso de prueba relacionado:** TC-LOGIN-002
- **Severidad:** Media
- **Prioridad:** Alta
- **Entorno:** Navegador Firefox, versión 1.0 de la aplicación
- **Estado:** Abierto

## Pasos para reproducir
1. Abrir la página de login
2. Ingresar usuario válido: usuario_prueba
3. Ingresar contraseña incorrecta: clave_incorrecta_123
4. Presionar "Entrar"

## Resultado esperado
Se muestra el mensaje "Usuario o contraseña incorrectos".

## Resultado real
La página se recarga sin mostrar ningún mensaje.
