## Cómo mantener este documento

- Cada requirement nuevo se agrega como una fila.
- Cada test case nuevo se enlaza con el requirement que verifica.
- Cada bug se enlaza con el test case que lo detectó.
- Si un requirement cambia, se revisan los test cases de su fila.
